## Project Description
A Java Maven-based system for managing bus drivers and buses.
Includes unit testing, integration testing, and CI/CD via GitHub Actions.

## How to Run Tests


mvn test

## Project Structure
- `src/main/java/com/busdriver/` - Main Java classes
- `src/test/java/com/busdriver/` - Unit and integration tests
- `drivers.txt` - Driver data storage
- `buses.txt` - Bus data storage
